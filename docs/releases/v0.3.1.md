## Tanager 0.3.1 — Keep the terminal focused (2026-11-27)

A bug-fix release for 0.3.0.

### Fixes

- After `cd` in a terminal, the keyboard focus jumped to the sidebar search field, so the next keys you typed went into the search field instead of the shell. The terminal now keeps the focus when the shell reports a new directory. (#143)

### Known limitations

- Opening a folder from the tree, and splitting panes, arrive in v0.4.0.
- The executable is not code-signed yet, so Windows SmartScreen may warn you (**More info → Run anyway**).

### Downloads

- `Tanager-0.3.1-windows-x64.msi`: per-user installer, no administrator rights needed.
- `Tanager-0.3.1-windows-x64.zip`: portable. Unzip it and run `Tanager\Tanager.exe`.

Requires Windows 10 or 11 (x64). A trimmed Java runtime is bundled.

## Tanager 0.3.1 — 터미널 포커스 지키기 (2026-11-27)

0.3.0 의 버그를 고친 릴리스입니다.

### 고친 것

- 터미널에서 `cd` 하면 키보드 포커스가 사이드바 검색칸으로 넘어가, 이어서 친 글자가 셸이 아니라 검색칸에 들어갔습니다. 이제 셸이 새 경로를 알려도 터미널이 포커스를 지킵니다. (#143)

### 알려진 한계

- 트리에서 폴더 열기와 창 분할은 v0.4.0 에 들어옵니다.
- 실행 파일에 아직 코드 서명이 없어 Windows SmartScreen 이 경고할 수 있습니다(**추가 정보 → 실행**).

### 내려받기

- `Tanager-0.3.1-windows-x64.msi`: 사용자 단위 설치 파일, 관리자 권한이 필요 없습니다.
- `Tanager-0.3.1-windows-x64.zip`: 설치 없이 쓰는 판. 압축을 풀고 `Tanager\Tanager.exe` 를 실행합니다.

Windows 10 · 11(x64)에서 동작합니다. 줄인 Java 런타임이 함께 들어 있습니다.
