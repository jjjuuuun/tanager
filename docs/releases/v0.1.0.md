## Tanager 0.1.0 — Scaffolding (2026-11-25)

The first build of Tanager. It opens an empty window and proves the build, test and packaging pipeline end to end. Real terminals arrive in v0.2.0.

### Highlights

- **Modular architecture** — hexagonal design split into Gradle modules, with dependency rules enforced by ArchUnit.
- **Platform selection** — the operating-system module is picked at start-up through `ServiceLoader`. (#17)
- **Windows packaging** — a portable zip with a trimmed Java runtime.

### Fixes

- Release workflow: the version argument now reaches the Windows packaging step. (#33)

### Documentation

- Project plan, software design description and architecture decision records.
- English and Korean README. (#28)
- MIT license. (#31)

### Downloads

- `Tanager-0.1.0-windows-x64.zip` — portable; unzip and run `Tanager\Tanager.exe`.

Requires Windows 10 or 11 (x64).
