## Tanager 0.2.0 — Single terminal (2026-11-26)

Tanager now runs a real terminal. Pick a shell on start-up and work in it — one terminal per window for now.

### Highlights

- **Real terminal** — WSL distros, Windows PowerShell 5.1 and cmd run in a ConPTY-backed terminal (JediTerm + pty4j). (#59, #64)
- **Shell detection** — the shells installed on this PC are found automatically; Docker Desktop's internal WSL distros are left out. (#48, #65)
- **Start-up shell picker** — choose a shell with the arrow keys, <kbd>Enter</kbd> or <kbd>1</kbd>–<kbd>9</kbd>, and optionally open it directly next time. (#71)
- **Restart on exit** — when the shell exits, the pane shows its exit code; <kbd>Enter</kbd> restarts it, <kbd>Tab</kbd> picks another shell, <kbd>Esc</kbd> closes the window. (#64)
- **Soft dark theme** — contrast-checked colour tokens and the bundled D2Coding font, so Korean text and IME input render correctly. (#62)

### Under the hood

- Workspace path value object and terminal session state machine. (#47)
- Default profile and start-directory resolution, and the start-session use case. (#61)

### Documentation

- UI design direction and colour tokens. (#40)
- Release procedure notes from v0.1.0. (#36)

### Known limitations

- One terminal per window. Splits arrive in v0.4.0.
- Directory history and the folder tree arrive in v0.3.0.
- The interface is in Korean for now.
- The executable is not code-signed yet, so Windows SmartScreen may warn you (**More info → Run anyway**).

### Downloads

- `Tanager-0.2.0-windows-x64.msi` — per-user installer, no administrator rights needed.
- `Tanager-0.2.0-windows-x64.zip` — portable; unzip and run `Tanager\Tanager.exe`.

Requires Windows 10 or 11 (x64). A trimmed Java runtime is bundled.
