## Tanager 0.4.0 — Splits (2026-11-28)

One window now holds as many terminals as you need. Split panes tmux-style, resize, swap, move and zoom them with the keyboard or the mouse. Open any folder from the sidebar tree in a new pane, in the same shell or in another one.

### Highlights

- **Split panes**: one window holds several terminals, each with its own shell and directory. Click a pane to focus it. The status bar follows the focused pane. (#140, #141, #161)
  - When the last pane closes, the app closes. Closing the window asks first if two or more shells are still running.
- **Open from the folder tree**: the tree is now a place to start work, not only a record. (#158)
  - Double-click a folder, or press <kbd>Enter</kbd>, to open it in a new pane to the right of the focused pane. Set `"openPlacement": "DOWN"` in `config.json` to open below instead.
  - The folder menu adds **Open here ▸ Right / Below** and **Open with another profile ▸**. The environment menu adds **New pane**, which starts that environment's default shell in its start directory (or home).
  - A folder that cannot be opened shows the reason in a tooltip and in the status bar, for example when its WSL distro is gone.
- **The same folder in another shell**: WSL and Windows paths are translated for you. `/mnt/c/work` opened in PowerShell starts in `C:\work`, and `C:\work` opened in WSL starts in `/mnt/c/work`. (#142)
- **Session menu**: click a session in the sidebar, or press <kbd>Enter</kbd>, to jump to its pane with the keyboard focus. Its menu has **Focus**, **New pane in the same folder ▸ Right / Below**, **Restart** (for exited shells) and **Close**. (#162)
- **Layout keys**: these keys work even while a shell has the focus. Nothing leaks into the shell. (#165)

  | Action | Keys |
  |---|---|
  | Split right / down | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>=</kbd> / <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>-</kbd> |
  | Move focus | <kbd>Alt</kbd>+<kbd>←↑→↓</kbd> |
  | Resize by 5 % | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←↑→↓</kbd> |
  | Zoom / unzoom | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
  | Close pane | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> |
  | Swap with the neighbour | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>←→</kbd> |

  Hover over the left side of the status bar to see this list in the app.
- **Pane header**: everything above can also be done with the mouse. (#167)
  - The header has four buttons: split right ▥, split down ▤, zoom □ and close ×. Tooltips show the matching keys. The keyboard focus stays in the terminal.
  - Double-click the header to zoom. The other panes are hidden, and their shells keep running.
  - Right-click the header for **Split ▸ Up / Down / Left / Right**, **Split with another profile ▸**, **Swap ▸** and **Close**.
- **Drag the dividers** to resize. Only a preview line moves while you drag, and the shell is resized once when you let go. Double-click a divider to reset it to 50:50. A pane never shrinks below 20 columns × 5 rows. (#168)
- **Drag and drop**: the drop target is highlighted while you drag, and <kbd>Esc</kbd> cancels. (#171)
  - Drag a pane by its header (≡) onto another pane. Drop it on an edge to move it there, or in the centre to swap the two panes. The shells keep running.
  - Drag a folder from the sidebar onto a pane. It opens in a new pane on that side of the pane you dropped it on.
- **Smooth transitions**: the focus border and the sidebar (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>) move in about 180 ms. They switch at once when Windows animation effects are turned off. (#159)
- **English interface**: the interface is in English, or in Korean when the Windows display language is Korean. Notices and error messages follow the same language. (#138, #139)

### Fixes since 0.3.0

- The terminal keeps the keyboard focus after `cd`. Typed keys no longer go to the sidebar search field. This fix was first shipped in 0.3.1. (#143)

### Under the hood

- The layout is an immutable tree. Splitting, closing, resizing, swapping and moving are pure functions. Focus by direction, divider hit tests and drop zones are pure geometry. (#135, #155)
- The workspace (panes, layout, focus and zoom) lives on the state actor. Keys, buttons, menus and drag and drop all call the same use cases. (#140, #161)
- The directory-tracking throughput test now compares against a baseline from the same run, so a busy machine no longer fails it. (#166)
- The checks before a push use at most three Gradle workers. The release process was updated as well. (#163, #153)

### Documentation

- [ADR-0016](https://github.com/jjjuuuun/tanager/blob/v0.4.0/docs/adr/0016-multi-pane-layout-and-lifecycle.md) explains multi-pane layout and pane lifetime.
- [ADR-0017](https://github.com/jjjuuuun/tanager/blob/v0.4.0/docs/adr/0017-ui-text-bundles-ko-en.md) explains Korean and English UI text.
- The README lists every layout key and mouse action.

### Known limitations

- Tabs, restoring the layout after a restart, and settings arrive in v0.5.0. For now, the next start opens a single pane again.
- Layout keys come before shell keys. For example, <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> move the focus instead of moving by word in bash.
- <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> and **Close** close a pane without asking, even while its shell is running.
- The executable is not code-signed yet, so Windows SmartScreen may warn you (**More info → Run anyway**).

### Downloads

- `Tanager-0.4.0-windows-x64.msi`: per-user installer, no administrator rights needed.
- `Tanager-0.4.0-windows-x64.zip`: portable. Unzip it and run `Tanager\Tanager.exe`.

Requires Windows 10 or 11 (x64). A trimmed Java runtime is bundled.

## Tanager 0.4.0 — 분할 (2026-11-28)

이제 창 하나에 터미널을 필요한 만큼 띄웁니다. tmux 처럼 창을 나누고, 크기 조정 · 교환 · 이동 · 줌을 키보드로도 마우스로도 할 수 있습니다. 사이드바 트리의 폴더를 새 창으로 열 수 있고, 같은 셸로도 다른 셸로도 열 수 있습니다.

### 주요 기능

- **창 분할**: 창 하나에 터미널 여러 개를 띄우고, 각 터미널은 자기 셸과 경로를 가집니다. 창을 누르면 포커스가 옮겨 가고, 상태줄은 포커스 창을 따릅니다. (#140, #141, #161)
  - 마지막 창을 닫으면 앱이 닫힙니다. 셸이 둘 이상 실행 중이면 앱 창을 닫기 전에 묻습니다.
- **트리에서 열기**: 트리가 기록만 하는 곳이 아니라 작업을 시작하는 곳이 됩니다. (#158)
  - 폴더를 더블클릭하거나 <kbd>Enter</kbd> 를 누르면 포커스 창 오른쪽에 새 창으로 엽니다. 아래에 열려면 `config.json` 에 `"openPlacement": "DOWN"` 을 씁니다.
  - 폴더 메뉴에 **여기서 열기 ▸ 오른쪽 · 아래**와 **다른 프로파일로 열기 ▸** 가 생깁니다. 환경 메뉴의 **새 창**은 그 환경의 기본 셸을 그 셸의 시작 경로(없으면 홈)에서 띄웁니다.
  - 열 수 없는 폴더는 툴팁과 상태줄에 이유를 보입니다. 예를 들어 그 폴더의 WSL 배포판이 지워진 경우입니다.
- **같은 폴더를 다른 셸로**: WSL 과 Windows 경로를 알아서 바꿉니다. `/mnt/c/work` 를 PowerShell 로 열면 `C:\work` 에서, `C:\work` 를 WSL 로 열면 `/mnt/c/work` 에서 뜹니다. (#142)
- **세션 메뉴**: 사이드바의 세션을 누르거나 <kbd>Enter</kbd> 를 누르면 그 창으로 가고 키보드 포커스도 옮겨 갑니다. 메뉴에는 **포커스**, **같은 경로에 새 창 ▸ 오른쪽 · 아래**, **재시작**(끝난 셸), **닫기**가 있습니다. (#162)
- **레이아웃 키**: 셸에 포커스가 있어도 동작하고, 셸에는 아무 글자도 가지 않습니다. (#165)

  | 동작 | 키 |
  |---|---|
  | 오른쪽 / 아래로 분할 | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>=</kbd> / <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>-</kbd> |
  | 포커스 이동 | <kbd>Alt</kbd>+<kbd>←↑→↓</kbd> |
  | 크기 조정(5 %) | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←↑→↓</kbd> |
  | 줌 / 줌 해제 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
  | 창 닫기 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> |
  | 이웃 창과 교환 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>←→</kbd> |

  상태줄 왼쪽에 마우스를 올리면 앱 안에서 이 목록을 볼 수 있습니다.
- **창 머리줄**: 위의 모든 동작을 마우스로도 할 수 있습니다. (#167)
  - 머리줄에 버튼 네 개가 있습니다. 오른쪽 분할 ▥, 아래 분할 ▤, 줌 □, 닫기 × 입니다. 툴팁에 해당 키가 보이고, 키보드 포커스는 터미널에 남습니다.
  - 머리줄을 더블클릭하면 줌합니다. 다른 창은 숨지만 셸은 계속 돕니다.
  - 머리줄을 오른쪽 클릭하면 **분할 ▸ 위 · 아래 · 왼쪽 · 오른쪽**, **다른 프로파일로 분할 ▸**, **교환 ▸**, **닫기**가 있습니다.
- **경계선 끌기**로 크기를 바꿉니다. 끄는 동안에는 미리보기 선만 움직이고, 놓을 때 셸 크기를 한 번 바꿉니다. 경계선을 더블클릭하면 50:50 으로 돌아갑니다. 창은 20열 × 5행보다 작아지지 않습니다. (#168)
- **끌어다 놓기**: 끄는 동안 놓을 곳이 강조되고, <kbd>Esc</kbd> 로 취소합니다. (#171)
  - 창 머리줄(≡)을 잡고 다른 창 위로 끕니다. 가장자리에 놓으면 그쪽으로 옮기고, 가운데에 놓으면 두 창을 바꿉니다. 셸은 끊기지 않습니다.
  - 사이드바의 폴더를 창 위로 끌어 놓으면, 놓은 창의 그쪽에 새 창으로 엽니다.
- **부드러운 전환**: 포커스 테두리와 사이드바(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>)가 약 180ms 동안 바뀝니다. Windows 의 애니메이션 효과를 끄면 바로 바뀝니다. (#159)
- **영어 화면**: 화면은 영어이고, Windows 표시 언어가 한국어면 한국어입니다. 알림과 오류 문구도 같은 언어를 따릅니다. (#138, #139)

### 0.3.0 이후 고친 것

- `cd` 한 뒤에도 터미널이 키보드 포커스를 지킵니다. 친 글자가 더 이상 사이드바 검색칸으로 가지 않습니다. 0.3.1 에서 먼저 나간 수정입니다. (#143)

### 내부 구조

- 레이아웃은 불변 트리입니다. 분할 · 닫기 · 크기 조정 · 교환 · 이동은 순수 함수입니다. 방향 포커스 · 경계선 판정 · 놓을 곳도 순수 기하 계산입니다. (#135, #155)
- 작업 공간(창 · 레이아웃 · 포커스 · 줌)은 상태 액터에 있습니다. 키 · 버튼 · 메뉴 · 끌어다 놓기가 모두 같은 유스케이스를 부릅니다. (#140, #161)
- 경로 추적 처리량 테스트는 같은 실행에서 잰 기준선과 비교합니다. 그래서 컴퓨터가 바빠도 실패하지 않습니다. (#166)
- push 전 검사는 Gradle 작업자를 최대 셋만 씁니다. 릴리스 절차도 고쳤습니다. (#163, #153)

- [ADR-0017](https://github.com/jjjuuuun/tanager/blob/v0.4.0/docs/adr/0017-ui-text-bundles-ko-en.md): 한국어 · 영어 화면 글자
- README 에 모든 레이아웃 키와 마우스 동작이 있습니다.

### 알려진 한계

- 탭, 다시 시작했을 때 레이아웃 복원, 설정은 v0.5.0 에 들어옵니다. 지금은 다음에 시작하면 다시 창 하나로 뜹니다.
- 레이아웃 키가 셸 키보다 먼저입니다. 예를 들어 <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> 는 bash 의 단어 이동 대신 포커스를 옮깁니다.
- <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> 와 **닫기**는 셸이 실행 중이어도 묻지 않고 창을 닫습니다.
- 실행 파일에 아직 코드 서명이 없어 Windows SmartScreen 이 경고할 수 있습니다(**추가 정보 → 실행**).
