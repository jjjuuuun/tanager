## Tanager 0.3.0 — History and folder tree (2026-11-27)

Tanager now remembers every directory you work in. Each shell reports where it is after every prompt. The left sidebar shows those directories as a folder tree per environment, with the running sessions hanging under the folder they are in.

### Highlights

- **Directory tracking**: WSL bash, Windows PowerShell 5.1 and cmd report their current directory after every prompt. Shell integration is installed automatically and keeps your existing prompt and themes. (#108, #111, #105)
  - Only directories are recorded. Commands and their output are never recorded.
- **Sidebar folder tree**: the left sidebar shows environments ("WSL · Ubuntu", "Windows"). (#126)
  - Under each environment are the folders you visited, with long single-child chains compressed.
  - Running sessions appear as "#1 bash", with a dot showing whether the shell is still running.
  - The tree updates as you `cd` and keeps what you had expanded and selected.
  - <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> shows or hides the sidebar.
- **Search**: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> filters the tree as you type and highlights the matches. <kbd>Esc</kbd> clears the search and puts the tree back as it was. (#128)
- **Folder menu**: right-click a folder, or press the menu key or <kbd>Shift</kbd>+<kbd>F10</kbd>, for these actions. (#129)
  - Copy path, pin and unpin, set an alias, hide and unhide, and delete from history.
  - <kbd>Delete</kbd> deletes the selected entry. Pinned or aliased entries ask before they are deleted.
  - The environment menu can show hidden folders, and expand or collapse everything.
- **Pinned section**: pinned folders stay at the top of the sidebar.
- **Current directory in the header**: the pane header and the status bar show where the shell is. Long paths are shortened in the middle; hover to see the full path. A warning mark appears when shell integration is unavailable. (#121)
- **Restart where you left off**: restarting an exited shell opens it in the last directory it reported. (#117)
- **History is saved** to `%APPDATA%\Tanager\state.json` within a second of a change and again when the app closes. (#103, #106)

### Fixes

- Text on colored backgrounds is readable again. For example, `ls` showed folders under `/mnt/c` as blue on green, at a contrast of about 1.3:1. Foreground colors are now adjusted to at least 4.5:1, while true-color output is left as the program chose. (#120)
- Windows paths show a backslash instead of `₩` on Korean Windows. (#127)
- A double quote in a WSL start directory could break out of the launch command. Such paths are now rejected. (#110)

### Performance

- Directory tracking scans large output about ten times faster, so `cat` of a 50 MB file is not slowed down by it. (#124)

### Under the hood

- All application state now changes on a single state actor that publishes events to the UI. (#101)
- History is a domain aggregate with pin, alias, hide and forget rules, projected into the sidebar tree as a pure function. (#97, #99, #102, #123)
- The scrollbars are thin and get thicker when you hover over them, and the inactive selection color is readable. (#122)

### Known limitations

- Opening a folder from the tree, and splitting panes, arrive in v0.4.0.
- Directory tracking needs shell integration. It is skipped in a shell started without it, and the header shows a warning mark.
- The interface is in Korean for now.
- The executable is not code-signed yet, so Windows SmartScreen may warn you (**More info → Run anyway**).

### Downloads

- `Tanager-0.3.0-windows-x64.msi`: per-user installer, no administrator rights needed.
- `Tanager-0.3.0-windows-x64.zip`: portable. Unzip it and run `Tanager\Tanager.exe`.

Requires Windows 10 or 11 (x64). A trimmed Java runtime is bundled.

## Tanager 0.3.0 — 이력과 폴더 트리 (2026-11-27)

이제 Tanager 가 작업한 모든 폴더를 기억합니다. 각 셸은 프롬프트마다 지금 있는 경로를 알립니다. 왼쪽 사이드바는 그 경로들을 환경별 폴더 트리로 보여 주고, 실행 중인 세션은 지금 있는 폴더 아래에 매달립니다.

### 주요 기능

- **경로 추적**: WSL bash, Windows PowerShell 5.1, cmd 가 프롬프트마다 현재 경로를 알립니다. 셸 통합은 자동으로 설치되며 기존 프롬프트와 테마를 그대로 둡니다. (#108, #111, #105)
  - 경로만 기록합니다. 명령과 출력은 기록하지 않습니다.
- **사이드바 폴더 트리**: 왼쪽 사이드바에 환경("WSL · Ubuntu", "Windows")이 보입니다. (#126)
  - 환경마다 방문한 폴더가 있고, 자식이 하나뿐인 긴 경로는 한 줄로 줄여 보입니다.
  - 실행 중인 세션은 "#1 bash" 처럼 보이고, 점으로 셸이 아직 실행 중인지 알 수 있습니다.
  - `cd` 할 때마다 트리가 바뀌고, 펼쳐 둔 것과 고른 것은 그대로 둡니다.
  - <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> 로 사이드바를 보이고 숨깁니다.
- **검색**: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> 로 입력하는 대로 트리를 거르고 맞는 곳을 강조합니다. <kbd>Esc</kbd> 는 검색을 지우고 트리를 원래대로 돌립니다. (#128)
- **폴더 메뉴**: 폴더를 오른쪽 클릭하거나 메뉴 키 · <kbd>Shift</kbd>+<kbd>F10</kbd> 을 누르면 다음 동작이 있습니다. (#129)
  - 경로 복사, 고정 · 고정 해제, 별칭, 숨기기 · 숨김 해제, 기록 삭제
  - <kbd>Delete</kbd> 는 고른 항목을 지웁니다. 고정 · 별칭이 있는 항목은 지우기 전에 묻습니다.
  - 환경 메뉴에서 숨긴 폴더를 보이거나, 모두 펼치고 접을 수 있습니다.
- **고정됨 섹션**: 고정한 폴더는 사이드바 맨 위에 남습니다.
- **머리줄의 현재 경로**: 창 머리줄과 상태줄에 셸이 있는 곳이 보입니다. 긴 경로는 가운데를 줄이고, 마우스를 올리면 전체 경로가 보입니다. 셸 통합을 쓸 수 없으면 경고 표시가 나옵니다. (#121)
- **있던 곳에서 다시 시작**: 끝난 셸을 다시 시작하면 마지막으로 알린 경로에서 뜹니다. (#117)
- **이력 저장**: 바뀐 뒤 1초 안에, 그리고 앱을 닫을 때 `%APPDATA%\Tanager\state.json` 에 저장합니다. (#103, #106)

### 고친 것

- 색 배경 위 글자를 다시 읽을 수 있습니다. 예를 들어 `ls` 가 `/mnt/c` 아래 폴더를 초록 바탕에 파란 글자(대비 약 1.3:1)로 보였습니다. 이제 글자색을 대비 4.5:1 이상으로 맞추고, 트루컬러 출력은 프로그램이 고른 색 그대로 둡니다. (#120)
- 한국어 Windows 에서 경로의 역슬래시가 `₩` 대신 `\` 로 보입니다. (#127)
- WSL 시작 경로에 큰따옴표가 있으면 기동 명령 밖으로 빠져나갈 수 있었습니다. 이제 그런 경로는 거부합니다. (#110)

### 성능

- 경로 추적이 큰 출력을 약 10배 빠르게 훑어, 50MB 파일을 `cat` 해도 느려지지 않습니다. (#124)

### 내부 구조

- 앱 상태는 모두 하나의 상태 액터에서 바뀌고, 그 액터가 UI 에 이벤트를 보냅니다. (#101)
- 이력은 고정 · 별칭 · 숨김 · 삭제 규칙을 가진 도메인 애그리거트이고, 순수 함수로 사이드바 트리에 투영됩니다. (#97, #99, #102, #123)
- 스크롤바는 얇고 마우스를 올리면 두꺼워지며, 포커스 없는 선택 색도 잘 보입니다. (#122)

### 알려진 한계

- 트리에서 폴더 열기와 창 분할은 v0.4.0 에 들어옵니다.
- 경로 추적에는 셸 통합이 필요합니다. 통합 없이 띄운 셸에서는 건너뛰고 머리줄에 경고 표시가 나옵니다.
- 지금 화면은 한국어만 있습니다(영어는 v0.4.0).
- 실행 파일에 아직 코드 서명이 없어 Windows SmartScreen 이 경고할 수 있습니다(**추가 정보 → 실행**).

### 내려받기

- `Tanager-0.3.0-windows-x64.msi`: 사용자 단위 설치 파일, 관리자 권한이 필요 없습니다.
- `Tanager-0.3.0-windows-x64.zip`: 설치 없이 쓰는 판. 압축을 풀고 `Tanager\Tanager.exe` 를 실행합니다.

Windows 10 · 11(x64)에서 동작합니다. 줄인 Java 런타임이 함께 들어 있습니다.
