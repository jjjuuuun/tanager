# 0006. UI 디자인 방향: 시안 D (배치 C + 다크 A · 라이트 B 색)

- 상태: 채택
- 날짜: 2026-11-25
- 관련: SDD §2.3 화면 구성 · §8.5 테마와 색 토큰, FR-UI-02 · 03 · 06, `.claude/rules/architecture.md`(색은 토큰으로만)

## 맥락
v0.1.0 은 FlatLaf 기본 라이트 테마에 빈 창 하나만 띄웠다. 사용자 의견은 "UI 가 굉장히 별로고 요즘 앱 느낌이 안 난다"였다.

SDD 에는 소프트 테마의 원칙만 있고 구체적인 모습은 없었다. 원칙은 순수 흑백 금지 · 둥근 모서리 · 배경 단차 · 포커스 창만 강조 테두리다. M2 에서 테마를 만들기 전에 사용자와 전체 느낌을 맞춰야 했다.

## 선택지
claude.ai 디자인 캔버스에 1280×800 시안을 만들어 비교했다. 시안 파일은 사용자 지시로 저장소에 넣지 않는다. 장면은 넷 다 같다: 폴더 트리, 분할 터미널, 상태줄.

| 시안 | 느낌 | 배치 |
|---|---|---|
| A · Midnight | 어두운 통합형(Windows Terminal · VS Code 계열) | 제목 표시줄에 붙은 탭, 사이드바, 좌우 분할, 창 사이 1px 선 |
| B · Paper | 밝은 카드형 | 따뜻한 미색 바탕에 떠 있는 카드, 알약 모양 탭 |
| C · Graphite | 아주 어두운 집중형 | 아이콘 레일, 가운데 검색, 위 1 + 아래 2 터미널, 오른쪽 도구함 패널, 떨어진 둥근 패널 |
| **D** | C 배치 + A 느낌 | C 의 배치를 A 의 색과 통합형(얇은 선)으로 |

## 결정
**D**(사용자 결정). 라이트 테마 색은 B 를 쓴다(사용자 결정). 시스템 · 다크 · 라이트 전환은 M5(FR-UI-01)다. 그 전에는 다크만 쓴다.

**배치**
- 제목 표시줄(40px): 앱 표시, 붙은 탭(활성 탭 위쪽 2px 강조선), 가운데 검색 칸(`Ctrl+Shift+F`), Windows 창 버튼
- 본문, 왼쪽부터
  - 아이콘 레일(48px): 작업 폴더 · 도구함 · 설정
  - 사이드바 폴더 트리(약 236px): 환경별 그룹 → 폴더 → 실행 중 세션
  - 터미널 영역
  - 도구함 패널(약 264px): 프로젝트 / 전체 공통 탭
- 창 머리줄(32px): 셸 · 경로 · 분할 · 줌 · 닫기 버튼
- 상태줄(28px): 환경 · 셸, 오른쪽에 CPU · 메모리(작은 막대) · 디스크 · WSL VM
- 영역은 배경 단차와 1px 선으로 나눈다. 포커스 창만 2px 강조색 테두리(FR-UI-03)
- M2 에 실제로 들어가는 것: 제목 표시줄, 터미널 창 1개, 상태줄의 환경 · 셸 표시
  - 레일 · 사이드바: M3
  - 분할: M4
  - 리소스 표시: M5
  - 도구함: M6

**색**: SDD §8.5 표가 원본이다. `SoftThemeTokensTest` 가 검사한다.
- 다크(A): 바탕 `#1B1E26`, 제목 · 레일 `#15181F`, 사이드바 `#181B23`, 선 `#262A35`, 글자 `#D6DAE3`, 보조 `#9AA1AF`, 강조 `#7AA2F7`
- 라이트(B): 바탕 `#F1EEE8`, 사이드바 `#F7F5F0`, 터미널 `#FBFAF7`, 선 `#E4E0D8`, 글자 `#34322E`, 보조 `#625E57`, 강조 `#2F6B5C`
  - 시안 B 는 흰 카드 `#FFFFFF` 와 글자 `#2A2926` 이었다. 순수 흰색 금지(FR-UI-02)와 본문 대비 13:1 상한에 맞춰 조금 바꿨다.

**글꼴**
- UI: Windows 기본(Segoe UI, 한글은 맑은 고딕으로 대체)
- 터미널: D2Coding 번들(FR-UI-06). 시안의 나눔고딕코딩은 웹에서 보이려고 쓴 대체 글꼴이다.

**Swing 구현 방향**
- FlatLaf 사용자 정의 창 장식(`JRootPane` window decorations)과 통합 제목 표시줄을 쓴다. 탭과 검색 칸을 제목 표시줄 안에 넣는다.
- 테마는 `soft-dark.properties` · `soft-light.properties`(FlatLaf 속성 파일). 모서리 `Component.arc` 8, 창 6.
- Windows 11 의 반투명(Mica · Acrylic)은 Swing 에서 안정적으로 낼 수 없어 쓰지 않는다. 단색 단차로 대신한다.

## 결과
- M2 의 테마 · 제목 표시줄 · 터미널 창 작업은 이 ADR 과 SDD §8.5 를 기준으로 한다. 세부 간격 · 크기는 구현하며 조정할 수 있고, 전체 느낌을 바꾸면 이 ADR 을 개정한다.
- SDD 그림 1(화면 구성)은 기능 배치 설명으로 남긴다. 실제 모습의 기준은 이 ADR 이다.
- 시안 원본이 저장소에 없으므로, 사용자가 실제 앱 화면을 보고 다시 확인한다. M2 중간 빌드와 릴리스 PR 의 수동 확인 항목에서 본다.
