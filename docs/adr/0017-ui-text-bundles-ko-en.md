# 0017. 화면 글자의 다국어(한국어 · 영어) 번들

- 상태: 채택(#136, 2026-11-27)
- 날짜: 2026-11-27
- 관련: #136 · #137, ADR-0010(테마 토큰과 같은 방식)

## 맥락
v0.3.0 까지 화면 글자는 코드 안에 한국어로 직접 들어 있었다. 영어 사용자는 앱을 쓸 수 없다. 화면 글자는 기능이 늘수록 많아진다(M4 분할 · M5 설정 화면). 그래서 나중에 옮길수록 비용이 커진다. 사용자 판단(2026-11-27)으로 M4 의 다른 작업보다 먼저 다국어 구조로 바꾼다.

정할 것:
1. 문장을 어디에 두고 어떻게 찾을지.
2. 언어를 어떻게 고를지.
3. 하위 계층(application · adapter · platform)이 만든 문장을 어떻게 할지.
4. 테스트가 PC · CI 의 언어에 따라 달라지지 않게 하는 방법.

## 선택지
**문장 위치**
- (a) **JDK `ResourceBundle` + `.properties`(UTF-8) 와 키 enum `Msg`.** 라이브러리를 더하지 않는다. 키를 잘못 쓰면 컴파일러가 잡는다.
- (b) 문자열 키만 쓴다. 오타를 실행 중에야 알게 된다.
- (c) 외부 i18n 라이브러리. 의존이 늘고 jdeps 모듈 축소에 신경 써야 한다.

**언어 고르기**
- (a) **OS 표시 언어(`Locale.Category.DISPLAY`)가 한국어면 한국어, 그 밖은 영어.** 시작할 때 한 번 정하고, 바꾸려면 다시 시작한다.
- (b) 실행 중에 바꾼다. 모든 컴포넌트를 다시 그려야 한다. 화면 언어를 바꾸는 일은 드물다.

## 결정
- 문장 (a). `tanager.ui.i18n`:
  - `Msg`(키 enum): `Msg.X.text(args…)`.
  - `Messages`: 번들 하나.
  - 번들 `tanager/ui/i18n/messages.properties`(영어, 기본) · `messages_ko.properties`(한국어).
  - 형식은 `MessageFormat` 이다. 작은따옴표는 `''` 로 쓴다. 인자는 문자열로 바꿔 넣는다 — 숫자에 자리 구분 쉼표가 붙지 않게.
- 언어 (a).
  - `ResourceBundle.Control.getNoFallbackControl` 을 쓴다. 영어를 골라도 JVM 기본 언어 번들로 넘어가지 않게 하기 위해서다.
  - 정적 가변 필드는 두지 않는다(java-style 8). 클래스를 올릴 때 한 번 정한 불변 값이다.
  - 설정으로 언어를 고르는 일은 설정 화면이 생기는 M5 에서 한다.
- 범위: 화면에 보이는 글자만 번들로 옮긴다. 로그 · 예외 메시지(개발자용)는 한국어로 남긴다.
- 하위 계층 문장(#137): 하위 계층은 문장 대신 구조화된 값(sealed record · enum + 인자)을 넘기고, ui 의 `NoticeText` 가 번들 문장으로 바꾼다.
  - 대상: 시작 알림 · 저장소 알림(`AppEvent.StoreProblem`) · 설정 경고(`IgnoredReason`) · 설정 오류(`ConfigError.Risk`) · 기동 오류 · 셸 통합(`Integration.Problem` · `FileProblem`) · 별칭 오류(`AliasProblem`) · 플랫폼 선택 오류.
  - 하위 계층의 `describe()` 는 로그용(한국어)으로 남기고 화면에는 쓰지 않는다.
  - 예외 메시지 · 파일 경로 · OS 가 준 이유(`detail`)는 번역하지 않고 그대로 넣는다. 위치 정보는 `(줄:열)` 처럼 언어와 무관한 형식으로 쓴다.
- 테스트:
  - ui 테스트 JVM 은 한국어로 고정한다(`-Duser.language=ko -Duser.country=KR`). 영어는 `Messages.of(Locale)` 로 따로 검사한다.
  - `MessageBundlesTest`: 두 번들의 키가 `Msg` 와 같고 인자 개수가 같은지 검사한다.
  - `UiTextSourceTest`: ui main 코드에 화면용 한글 리터럴이 없는지 검사한다.

## 결과
- 좋아지는 점
  - 영어 OS 에서 ui 가 그리는 글자가 영어가 된다.
  - 번역이 빠지면 테스트가 실패한다.
  - 새 화면 글자를 코드에 직접 쓰면 `UiTextSourceTest` 가 막는다.
- 대가
  - 화면 글자를 더할 때마다 키 · 두 번들 세 곳을 고친다.
  - 영어 화면의 글자 길이로 생기는 배치 문제는 눈으로 확인해야 한다.
- 다른 언어를 더하려면 `messages_<언어>.properties` 를 추가하고 `Messages.of` 의 고르기 규칙을 넓힌다.
